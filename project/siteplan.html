AZ Basketball Universe - Site Plan

Site Name

AZ Basketball Universe

This name represents a central hub for basketball players and fans across Arizona, focused on community, pickup games, and improving skills.

Domain: azbball.com (not required for class)

Site Purpose

This website provides a hub for basketball enthusiasts in Arizona. Users can find pickup games, learn basketball tips, explore fun facts, sign up for a newsletter, and track local player and team stats.

Scenarios

  • How can I find a pickup basketball game near me?
  • How do I sign up for the basketball newsletter?
  • How can I submit stats for my team or players?
